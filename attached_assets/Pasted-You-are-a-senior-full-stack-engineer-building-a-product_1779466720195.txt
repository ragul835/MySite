## 1. PROJECT INITIALIZATION

### Tech Stack
- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript (strict mode)
- **Styling**: Tailwind CSS 3+
- **UI Components**: shadcn/ui
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Fonts**: Inter (primary), Poppins (headings) — via Google Fonts

### Setup Commands
npx -y create-next-app@latest ./ --typescript --tailwind --eslint --app --src-dir --import-alias "@/*" --no-turbopack

npx -y shadcn@latest init

npm install framer-motion lucide-react clsx tailwind-merge

- Include JSDoc comments for complex props
- Use forwardRef where applicable

- ServiceCard: icon + title + description + hover glow

## 9. ANIMATION GUIDELINES

Use Framer Motion for all animations:
- Page transitions: fade + slight y-translate
- Section reveals: staggered children with useInView
- Card hovers: scale(1.02) + blue border glow + shadow elevation
- Button hovers: subtle scale + blue gradient shift
- Navbar: blur increase on scroll
- Hero: text reveal with staggered word animation
- Tech tabs: smooth content crossfade
- Numbers: count-up animation with useInView trigger
- Keep all animations subtle and professional (duration: 0.3-0.6s, ease: easeOut)
- Respect prefers-reduced-motion
